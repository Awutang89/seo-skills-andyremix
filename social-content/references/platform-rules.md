# Platform rules

Resolve which drafts to write, then read the matching platform files:

- X: `platforms/x.md`
- X Premium or long X posts: `platforms/x-premium.md`
- Meta Threads: `platforms/threads.md`
- LinkedIn: `platforms/linkedin.md`

Other platforms (Instagram, TikTok, YouTube, Pinterest, Reddit) and one-article-into-many repurposing belong to content-atomizer. Multi-slide LinkedIn documents are a separate format. This skill writes feed posts, optionally with one image.

## Resolution

- One platform named: one draft for it.
- Several named: one draft for each, nothing more.
- "A social post" with no platform: one short question, unless the source plainly points to one platform.
- The idea clashes with the saved pillars or audience: ask how it connects, or offer a bridge, before drafting.
- X routes to `x-premium.md` only when the person says they have long posts, the saved profile says so, or they ask for a long X post. Otherwise `x.md`.

A missing requested platform and an extra unrequested platform are both hard failures.

## Fan-out

Same nugget, different reading modes. Never lazy rewording.

- Standard X: the punchiest claim, contrast or proof snippet.
- X Premium: the same X-style opening; extra room used only when the story, proof, argument or nuance needs it.
- Meta Threads: a strong first line, caption energy, a friendly edge, or a short conversational sequence.
- LinkedIn: fuller setup, the stakes, the context, the proof.

One proof ledger across all versions; structure and emphasis change. Read every requested platform file before drafting any of them.

## Conditional formatting

Platform norms are starting points. The person's real examples win unless they would break the platform or hurt credibility.

- Hashtags: only with support from the examples or brief.
- Dashes: zero by default (house rule); match the examples if they use them.
- Emojis: only with support from the examples.
- Bullets and numbering: when they match the person's style or genuinely make the post clearer.
